# InternConnect — HTML5 + Bootstrap prototype

## What's included
- `index.html` — landing page
- `internships.html` — sample internship listings with working keyword, field, and location filters
- `login.html` — role selection and demo navigation
- `register.html` — front-end registration form validation
- `student-dashboard.html` — sample student dashboard and progress-report/profile modals
- `company-dashboard.html` — sample company dashboard and internship-posting modal
- `coordinator-dashboard.html` — sample coordinator dashboard
- `assets/css/styles.css` — custom styling
- `assets/js/app.js` — small front-end interactions

## How to run
1. Extract the ZIP file.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code and use Live Server.
3. Internet access is needed for the Bootstrap CDN stylesheet and JavaScript bundle.

## Important prototype limitations
This is the first front-end version only. The data is sample content; authentication, secure account storage, file uploads, database persistence, messaging, real match scoring, notifications, evaluations, and report exports are not connected. Those require backend and database decisions before production use.

## Suggested next step
Agree on the backend stack and database, then connect registration/login, role-based access, persistent student/company profiles, internship CRUD, applications, and a clearly defined matching-score formula.
